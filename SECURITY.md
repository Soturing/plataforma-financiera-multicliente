# Seguridad del proyecto

No publique vulnerabilidades, credenciales ni muestras de datos financieros en issues, discusiones o pull requests.

Reporte el hallazgo directamente al responsable de seguridad de la consultora mediante el canal interno autorizado. Incluya únicamente la información mínima necesaria para reproducirlo y use datos sintéticos. Si el hallazgo implica una credencial expuesta, revóquela primero y trátela como comprometida aunque el repositorio sea privado.

Los incidentes que puedan cruzar organizaciones, evadir permisos o exponer nómina, recetas, inventarios, proveedores, deuda, ventas o ganancias tienen prioridad crítica.
